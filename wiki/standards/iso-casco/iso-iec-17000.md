# Summary

**ISO/IEC 17000:2020 (Conformity assessment — Vocabulary and general principles)** is the master architectural standard produced by the ISO Committee on Conformity Assessment (**CASCO**)[^iso-iec-17000].

It specifies the standardized terminology and structural concepts governing all testing, inspection, certification, and accreditation standards worldwide.

# The Functional Approach to Conformity Assessment

Every conformity assessment activity—whether internal self-declaration (Module A) or high-assurance third-party certification (Module H1 / EUCC High)—follows the universal 5-stage **Functional Approach**:

```
+-------------------------------------------------------------------+
|               ISO/IEC 17000 FUNCTIONAL APPROACH                   |
+-------------------------------------------------------------------+
| 1. SELECTION                                                      |
|    - Choosing the object of conformity assessment                 |
|    - Identifying the specified requirements (standards, laws)     |
|    - Selecting sampling plans and assessment methods              |
+-------------------------------------------------------------------+
| 2. DETERMINATION                                                  |
|    - Developing objective evidence through testing, inspection,   |
|      auditing, or design evaluation                               |
+-------------------------------------------------------------------+
| 3. REVIEW                                                         |
|    - Verification of the suitability, adequacy, and effectiveness |
|      of determination activities before making an attestation     |
+-------------------------------------------------------------------+
| 4. ATTESTATION                                                    |
|    - Issuance of formal statement of conformity (Certificate of   |
|      Conformity, Declaration of Conformity, Test Report)          |
+-------------------------------------------------------------------+
| 5. SURVEILLANCE (Optional/Ongoing)                                |
|    - Systematic iteration of assessment activities to maintain   |
|      the validity of the statement of conformity over time        |
+-------------------------------------------------------------------+
```

# Core Standardized Terminology

- **First-party assessment**: Conformity assessment performed by the person or organization that provides the object (e.g. manufacturer self-declaration under Module A).
- **Second-party assessment**: Conformity assessment performed by a person or organization that has a user interest in the object (e.g. enterprise customer auditing a software supplier).
- **Third-party assessment**: Conformity assessment performed by a person or body that is independent of the provider and user (e.g. Notified Body, accredited testing laboratory).
- **Accreditation**: Third-party attestation related to a conformity assessment body conveying formal demonstration of its competence to carry out specific tasks.
