# Summary

**Module C (Conformity to type based on internal production control)** is that part of a conformity assessment procedure whereby the manufacturer fulfils obligations in points 2 and 3, ensuring products conform to the type approved under Module B[^decision-768-2008-ec].

# Normative Procedure
1. **Manufacturing**: Manufacturer ensures the manufacturing process guarantees conformity with the approved type in the EC-type examination certificate.
2. **Declaration and CE Marking**: Manufacturer affixes CE marking and draws up the written EU declaration of conformity.
