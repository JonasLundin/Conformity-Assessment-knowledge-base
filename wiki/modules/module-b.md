# Summary

**Module B (EU-Type Examination)** is the premier design-phase conformity assessment procedure under Annex II of Decision No 768/2008/EC[^decision-768-2008-ec][^blue-guide-2022].

Module B covers exclusively the **design phase** of a product. It does not allow placing products on the market or affixing the CE marking on its own; it must always be followed by a production-phase module (Module C, C1, C2, D, E, or F).

# Operational Stages of EU-Type Examination

```
+---------------------+        +--------------------+
|     Manufacturer    |        |    Notified Body   |
+---------------------+        +--------------------+
          |                              |
          | 1. Application & Tech Docs   |
          |----------------------------->|
          |    (Specimens / Type sample) |
          |                              | 2. Technical Evaluation:
          |                              |    - Verify standards application
          |                              |    - Perform tests & examinations
          |                              |    - Author Evaluation Report
          |                              |
          | 3. Certificate Issuance      |
          |<-----------------------------|
          | (EU-Type Examination Cert)   |
          |                              |
          v                              v
+---------------------------------------------------+
|  Subsequent Production Phase Required:            |
|  - Module C (Internal production control to type) |
|  - Module D (Production quality assurance)        |
|  - Module E (Product quality assurance)           |
|  - Module F (Product verification)                |
+---------------------------------------------------+
```

# Evaluation Scope & Certificate Maintenance
- **Examination Scope**: The notified body evaluates the adequacy of technical design through examination of technical documentation and testing of one or more representative specimens of the complete product.
- **EU-Type Examination Certificate**: Contains manufacturer details, examination conclusions, conditions of validity, and data necessary for identification of the approved type.
- **Validity & Review**: Certificates are subject to periodic review (typically 5 years) or immediate reassessment upon significant architectural or standard changes.

# Sector Usage
- **CRA Article 32(2) & 32(3)**: Standard assessment route for Important Class I and Class II products (Module B + C).
- **AI Act Article 43(2)**: Mandatory route for high-risk biometric systems not covered by harmonised standards.
