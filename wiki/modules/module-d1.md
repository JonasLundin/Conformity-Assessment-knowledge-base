# Summary

**Module D1 (Quality assurance of the production process)** allows a manufacturer to apply production quality assurance directly against technical documentation without a prior Module B EC-type examination[^decision-768-2008-ec].

# Normative Structure
- The manufacturer establishes technical documentation and operates an approved quality system for production and inspection.
- A notified body assesses the quality system and carries out surveillance.
